# Mehro nisa Malik — Clinical Dietician Practice Website

A modern, responsive practice website for Mehro nisa Malik, Registered Clinical Dietician (MSc Clinical Nutrition & Dietetics).

## 🌟 Features
- **Responsive Hero Section** with consultation booking call to action.
- **Services & Specializations:** Metabolic health, PCOS/Hormonal balance, diabetes management, gut health.
- **Conditions Treated:** Interactive clinical condition cards.
- **Nutrition Insights / Blog:** Evidence-based nutrition articles.
- **Testimonials & FAQs:** Social proof and consultation process details.
- **Contact & Appointment Form:** Integrated booking workflow.

## 🚀 Running Locally

1. Ensure [Node.js](https://nodejs.org/) is installed.
2. Run the local server:
```bash
node server.js
```
3. Open your browser at [http://localhost:3000](http://localhost:3000).

Or open `index.html` directly in any web browser.
